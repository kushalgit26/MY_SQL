# MySQL Data Analysis – Maven Movies Project

## 📌 Project Overview
This project contains SQL queries written to analyze the Maven Movies database.
The analysis covers inventory, film categories, replacement cost, and customer details.

- MySQL Workbench
- Maven Movies Database

## 📊 Key SQL Concepts

- GROUP BY
- Aggregate Functions (COUNT, AVG, SUM)
- ORDER BY
